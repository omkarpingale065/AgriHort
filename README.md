# Omkar Pingale's Portfolio Website

A modern, responsive portfolio website built with HTML5, CSS3, and JavaScript. Features a clean design, smooth animations, and mobile-first responsive layout.

## 🌟 Features

- **Modern Design**: Clean, professional layout with gradient backgrounds and smooth animations
- **Responsive**: Mobile-first design that works perfectly on all devices
- **Interactive**: Smooth scrolling, hover effects, and dynamic animations
- **Accessible**: Keyboard navigation support and focus indicators
- **Performance**: Optimized loading with lazy loading and efficient animations
- **SEO Ready**: Semantic HTML structure and meta tags

## 🚀 Sections

- **Hero Section**: Eye-catching introduction with animated elements
- **About**: Personal information and skills showcase
- **Services**: Professional services offered
- **Portfolio**: Project showcase with hover effects
- **Contact**: Contact form with validation and social links

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and accessibility features
- **CSS3**: Modern styling with Flexbox, Grid, and animations
- **JavaScript**: Interactive features and smooth user experience
- **Font Awesome**: Beautiful icons throughout the site
- **Google Fonts**: Inter font family for clean typography

## 📱 Responsive Breakpoints

- **Desktop**: 1200px and above
- **Tablet**: 768px to 1199px
- **Mobile**: Below 768px

## 🎨 Color Palette

- **Primary**: #6366f1 (Indigo)
- **Secondary**: #667eea to #764ba2 (Gradient)
- **Accent**: #ffd700 (Gold)
- **Text**: #333333 (Dark Gray)
- **Background**: #f8fafc (Light Gray)
